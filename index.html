 A BETTER WAY TO BRIEF

把思考留给自己，
把制作交给 Agent。

YoursPPT 帮你先确定目标和每页逻辑，再整理素材、选择风格，最后调用本机 Agent 生成 PPTX 或 HTML，也可导出完整工作包。

  1. 01
    说清楚你要讲什么

    一页一个主要任务，让结论有支撑，让转场有理由。

  2. 02
    备齐素材与风格

    拖入真实文件，选择主题色和版式方向，看到即时预览。

  3. 03
    由本机 Agent 生成演示

    通过本机服务选择 Agent，生成 PPTX 或 HTML；也可离线导出工作包。

右上角“设置”可选择导出位置、保存和读取草稿。未完成草稿也会完整保留；需要制作时再补齐必填信息。
 EDITOR QUICK GUIDE

Markdown 语法与快捷键

直接在文字中输入语法。光标进入时显示标记，离开后呈现排版；点击表格可编辑原文。

基本语法

标题
# 一级标题
## 二级标题
粗体 / 斜体
**粗体** · *斜体*
列表 / 任务
- 要点 · 1. 步骤
- [ ] 待办 · - [x] 完成
引用 / 链接
> 引用内容
[名称](https://example.com)
代码
`行内代码`
代码块用三反引号包围，可在开头注明语言。
表格
| 项目 | 数值 |
| --- | --- |
| A | 1 |

Ctrl / ⌘ + Z

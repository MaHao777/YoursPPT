# YoursPPT 制作 Brief 示例

这是简化的内容示意，不是实际导出文件。实际导出包含全部输入、逐页字段、包内链接、素材清单、风格与 Skill 入口。

## 基本信息

- 主题：把汇报准备变成可重复的工作流
- 听众：希望优化汇报流程的团队
- 目标：让听众理解如何把自己的思考完整交给 Agent 执行
- 风格：瑞士网格 / 克莱因蓝
- 交付：可编辑 PPTX

## 第 1 页

### 页面标题

好看的页面，需要清晰的思考

### 页面目的

说明为什么要先确定逻辑

### 关键结论

汇报者先想清楚要表达什么，再进入视觉制作。

### 支持点

明确听众与目标；每页只承担一个主要任务。

### 视觉要求

一句核心判断，留出足够空白，不虚构统计数字。

### 讲稿备注

结合汇报者自身经历解释问题。

## Agent 边界

保留用户确定的观点、页序与承接。发现事实或论证缺口先确认，不编造数据、引用或因果关系。实际工作包从根目录 `brief.md` 开始，素材访问使用 `references/manifest.json` 中的相对路径。
